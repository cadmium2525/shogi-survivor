# 将棋サバイバー MVP 実装計画

## 採用仕様

提供されたWord文書「ゲーム企画書｜将棋ローグライク・オートバトラー MVP 0.1」と「Codex実装指示書｜将棋ローグライクMVP」を根拠とする。ゲームルールは企画書、技術構成・処理順・テスト条件は実装指示書に従う。抽出テキストは `artifacts/spec-1.txt` と `artifacts/spec-2.txt`。

作業開始時のディレクトリに既存ソースとGit履歴はなかったため、新規構成として TypeScript + React + Vite、Vitest を採用する。和紙・墨・朱を基調とした画面を維持し、スマートフォンからGitHub Pagesで遊べる静的アプリケーションとする。有料API、バックエンド、アカウント登録、外部素材への依存は設けない。

## 実装するルール

- 盤面は5列×5行。味方先手。通常は味方陣営1枚→敵陣営1枚の交互行動。AIは毎回、全自軍駒の全合法手から1手を選ぶ。
- 王は8方向、歩は前、金は前・前斜め・横・後ろ、飛は縦横の射線に従う。王捕獲で勝敗を決める独自ルールを画面に明記する。
- 初期所持は王1枚・歩1枚。味方配置は下2段、王必須、重複不可、出撃最大6枚。控えと位置交換を実装する。
- 敵編成は第1戦が王＋歩、第2戦が王＋歩＋歩、第3戦が王＋金＋歩、第4戦が王＋金＋歩＋歩、第5戦が王＋飛＋金＋歩。配置は固定し、戦闘前に公開する。
- 鉄壁は最初の捕獲を無効化し、攻撃側を移動元に留める。捕獲不成立のため分裂・連撃は発動しない。
- 分裂は捕獲した側の能力。捕獲成功時、移動元の空きマスに能力なしの歩を1枚召喚する。盤上の同陣営最大8枚。
- 連撃は捕獲成功時に同陣営の追加1行動を発生させる。追加行動からは連撃しない。追加行動も陣営内の全候補から選び、1半手を数える。
- オセロ反転は駒能力ではなく、第2戦勝利で確定獲得する遺物。行動した陣営について盤面全体を8方向に1回だけ検査する。王が含まれる列は不成立。対象を上→下・左→右で反転し、同陣営最大8枚を守る。
- 合法手なしはパス。双方連続パスまたは80半手で敗北。王捕獲の勝敗を上限判定より先に処理する。
- 毎勝利、王以外の3候補から必ず駒1枚を獲得。第3戦勝利以降は能力付き候補を用意する。第5戦も報酬選択後にクリアする。

## 1半手の処理順

1. 全合法手を生成し、共通AIで行動を選択する。合法手なしならパスする。
2. 敵への攻撃は鉄壁を先に判定する。防御成功なら盾だけを消費する。
3. 通常捕獲は対象を除去し、攻撃側を移動する。移動元に分裂の歩を召喚する。
4. 遺物が有効なら、行動した陣営のオセロ反転を1回検査する。パスでは検査しない。
5. 王捕獲による勝敗を判定する。
6. 捕獲成功かつ連撃なら、追加行動中でないときだけ同陣営に追加1行動を設定する。それ以外は陣営交代する。
7. 半手を1増加し、勝敗未決定なら80半手・双方連続パスの敗北を判定する。

## AIと再現性

両陣営で同じ評価関数を使う。敵王捕獲、自王の直後の被捕獲、自王への脅威除去、駒の捕獲価値、前進、射線、護衛を評価する。鉄壁残数と、一手先の相手の最良捕獲を考慮する。金は護衛、歩は前進、飛は射線、王は安全を重視する。同点は駒ID→移動先y→xの昇順で固定する。評価内訳を理由としてログへ返し、再生速度や描画に結果を依存させない。

## 実装・検証の順序

1. 型と定数を固定し、移動・能力・AI・戦闘と進行を分担する。
2. 純粋関数のVitestを整備し、必須ケースと能力の相互作用を検証する。
3. React画面へ統合し、配置・交互戦闘・3択報酬・遺物・5戦の終了まで接続する。
4. 画面操作、狭い幅、キーボード、ログと危険マスを確認する。
5. 最終仕様で単体テストと本番ビルドを実行し、結果を `docs/TESTING.md` に記録する。
6. 相対パスの静的ビルドと無料Pages公開手順を整備する。追加依頼で指定された `cadmium2525/shogi-survivor` へpushし、GitHub PagesのActions公開を有効化。公開URLでスマートフォン相当の画面幅と全5戦の動作を検証する。

## 最小限の仮定・対象外

固定座標・固定報酬と評価重みは実装データで定義する。戦闘の一時的な召喚・反転は所持駒へ持ち越さず、所持駒は次戦で再編成できる。鉄壁は各戦で初期化する。王手・詰み・成り・持ち駒・二歩・打ち歩詰め、桂・銀・角・香、メタ成長、ショップ、通貨、能力の付け替え・合成・レアリティ抽選は対象外。

セーブはスマートフォン利用を補助するMVP外の小さな追加機能として、同じブラウザ内だけに実装する。戦闘中の再読込は一時停止で再開し、アカウントやメタ成長、端末間同期は設けない。
